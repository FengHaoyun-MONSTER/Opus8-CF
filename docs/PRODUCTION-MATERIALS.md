## 🟥 一期必需（P0–P2 命脉闭环）

1. **GitHub 仓库**
   - [ ] 在 `Opus8-CF` 目录 `git init` 后要推到哪个 GitHub 仓库？（给我仓库名/URL，或授权我用本地 gh 创建）
   - [ ] 是否已装并登录 `gh`（你说可用）——确认账号无误。

2. **一个"主" Cloudflare 账号 + 一个域名**（跑控制面 + 管理站）
   - [ ] Cloudflare 账号邮箱
   - [ ] Account ID
   - [ ] **API Token**（权限：Workers Scripts 编辑、Pages 编辑、D1 编辑、KV 编辑、Zone/DNS 编辑）
   - [ ] 一个已托管在该 CF 账号的**域名**（用于控制面 API、订阅端点、管理站）；告诉我根域名，子域我来规划（如 `api.` `sub.` `admin.`）。

3. **控制面基础设施**（可我用 wrangler 建，但需上面 Token）
   - [ ] 是否允许我用 wrangler 创建 **D1 数据库** 与 **KV 命名空间**？（是/否）

4. **密钥（我生成也行，你确认）**
   - [ ] 管理后台**管理员密码**（你定，或我生成强随机后给你）
   - [ ] 节点↔控制面 **HMAC 共享密钥**（我生成随机）
   - [ ] 管理 **JWT 签名密钥**（我生成随机）
   > 以上三个若你没偏好，我会各生成一串强随机值，写进 Secrets，并把明文一次性给你留存。

   - [ ] 账号别名（如 `acc-a`）
