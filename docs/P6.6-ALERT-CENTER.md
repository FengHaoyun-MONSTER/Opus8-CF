# P6.6 统一异常告警中心

运营总览每 30 秒读取一次控制面状态，并把用户限制、边缘节点、落地机和按节点优选
IP 池统一转换为告警。严重告警始终排在一般告警之前。

## 告警来源

### 用户

- 用户被停用或已过期；
- 流量配额耗尽或接近配额；
- 同时在线 IP 或 24 小时 IP 变化达到限制。

### 边缘节点

- 节点被停用、降级或摘除；
- 真实 VLESS 健康检查从未执行或超过 30 分钟没有更新；
- 直连、落地/WARP 探测返回错误。

### 落地机

- 已启用的 Dante SOCKS5 落地机探测失败；
- 落地机从未检查或超过 30 分钟没有更新。

### 优选 IP

- 版本 3 优选池不存在或无法解析；
- 可用节点没有未过期的双视角安全候选；
- 优选记录的主机名与当前节点不一致；
- 记录缺少 GitHub Runner 或落地 VPS 验证；
- 最早一组记录将在 90 分钟内过期；
- 所有可用节点均回退域名时产生严重告警。

优选 IP 告警只影响运营可见性，不改变订阅侧的安全判断。订阅继续使用同一套版本、
主机名、双视角和有效期准入规则。

## 面板操作

- “全部 / 严重 / 一般”可以快速筛选告警；
- 总览卡片分别显示严重告警和一般告警数量；
- 每条告警提供“处理”入口，跳转至用户、节点或落地机页面；
- 节点卡片同时显示当前优选池覆盖数。

面板最多返回 50 条当前告警，不持久保存用户 IP 明文，也不包含服务器凭据。
外部邮件、Telegram 或企业微信通知可以在后续阶段基于相同告警结构接入。
