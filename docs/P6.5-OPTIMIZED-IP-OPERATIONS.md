# P6.5 按节点优选 IP 运营面板

“节点管理”页面同时读取节点注册表与控制面的版本 3 优选 IP 池，并按 Node ID
合并展示。页面每分钟刷新一次数据，每 30 秒更新剩余有效期。

## 状态说明

- **优选生效**：该节点存在未过期记录，记录主机名与当前注册主机名一致，并且订阅侧已启用优选 IP。
- **域名回退**：该节点没有未过期的双视角候选，或者节点主机名已经变化。只有这个节点回退，其他节点继续使用各自的安全 IP。
- **域名模式**：控制面的 `USE_OPTIMIZED_IPS` 未启用，所有节点继续使用域名连接。
- **未下发**：节点已被停用或健康检查摘除，不会进入用户订阅。

每个生效节点会显示：

- 当前写入订阅的 IP，可点击复制；
- 最近验证时间；
- 精确过期时间与动态倒计时；
- GitHub Runner、落地 VPS 双视角验证说明。

面板只读取控制面已经完成安全过滤的池，不展示探测用户、订阅令牌、SSH 凭据或
SOCKS5 凭据。

## 手动重新优选

“打开重新优选任务”会进入仓库的 `optimize-ip` GitHub Actions 页面。拥有仓库写入
权限的运营人员可以选择 **Run workflow** 立即执行。

管理面板不会存储 GitHub Personal Access Token，也不会把 GitHub 写入权限交给
Cloudflare Pages。任务仍由 GitHub Secrets 提供探测与发布所需凭据，结果由控制面
进行版本、节点主机名、双视角和有效期校验。

自动任务仍每 4 小时执行一次；单次任务没有为某个节点找到合格候选时，该节点安全
回退域名，不会复用其他节点未经验证的 IP。
